# 📊 UPI Transactions Dashboard Analysis

An interactive **Microsoft Excel Dashboard** that analyzes **UPI (Unified Payments Interface)** transaction data to uncover patterns in payment behavior, app usage, fraud indicators, and regional/temporal trends across India.

# 📖 Project Summary

This project visualizes **5,02,887 UPI transactions** worth **₹44.25 Crore**, built entirely in **Microsoft Excel** using **Pivot Tables, Pivot Charts, Slicers, Conditional Formatting, and Excel Maps**.

The dashboard provides an interactive and filterable view of UPI transactions, enabling users to analyze:

- 📈 Transaction Volume
- 💰 Transaction Amount
- 💵 Cashback Distribution
- ✅ Success & Failure Rate
- ⚠️ Suspected Fraud
- 🏦 Bank-wise Analysis
- 📱 UPI App-wise Analysis
- 🗺️ State-wise Performance
- 🛒 Transaction Type Analysis
- ⏰ Hourly & Daily Trends


# 🎯 Project Objectives

- Monitor UPI transaction performance.
- Identify transaction trends and peak usage hours.
- Compare leading UPI applications.
- Analyze bank-wise transaction distribution.
- Detect suspicious/fraudulent transactions.
- Understand regional transaction patterns across India.

# 📌 Key Insights

- 📱 **PhonePe** dominates the UPI ecosystem with nearly **50%** market share.
- 💳 **P2M transactions** account for the highest transaction value.
- ✅ Overall transaction success rate is **91%**.
- ⚠️ Approximately **17,089 transactions** are flagged as suspected fraud.
- 🏙️ Maharashtra, Karnataka, and Delhi generate the highest transaction value.
- 🌆 Peak transaction activity occurs during **5 PM – 8 PM**.
- 🏦 Both private and public sector banks contribute significantly to UPI transactions.
